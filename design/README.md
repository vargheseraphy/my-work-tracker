# Design prototypes

Open `index.html` in a browser. Each file is self-contained (styles and scripts inside) and the
files link to each other, so keep them in this folder together.

These are the visual source of truth for the build: layout, copy, spacing, states. All names,
numbers, accounts and tasks in them are invented sample data. See docs/DESIGN.md for how each
screen maps to a route and what is deliberately different in the real app.
