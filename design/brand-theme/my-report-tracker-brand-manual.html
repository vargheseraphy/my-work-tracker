Colour

Ink, canvas and four orb hues

Text never uses light grey. Secondary text stays dark navy in light mode and near-white in dark mode. The orb hues are for backgrounds and glass only. Never set text in them. The six chart colours are for categories and are separate from the accent.

Typography

One humanist sans, one data mono

Segoe UI Variable on Windows, with Noto Sans everywhere else. IBM Plex Mono is used only for eyebrows, axis labels and code. Numbers use tabular figures so columns line up.

Backgrounds

Eight grounds for heroes and bands

Use one ground per page, behind the top band only. Work areas sit on the plain canvas. Orb Field is the signature ground. Ink Night is fixed dark and suits covers and splash screens in either theme.

Glass

Six glass treatments

Glass only works over colour, so always place it on an orb ground. Frosted is the default for KPI tiles. Use Prism Edge once per screen for the hero element. Text on glass is always full ink.

Rules

Do and don't

Six rules that keep screens consistent.

Do

  • Keep all text at ink, ink 2 or muted. Each passes AAA on its surface.
  • Place glass only over an orb or aurora ground.
  • Use one accent button per view, for the main action.
  • Pair every status colour with a word, such as Target met.
  • Use tabular figures for counts, money and dates.
  • Check every screen in both themes before shipping.

Don't

  • Set text in light grey or in orb colours.
  • Round buttons into pills or use corners above 14px.
  • Stack glass on glass, or use glass on a plain white canvas.
  • Use more than one background ground on a page.
  • Use chart colours for buttons or links.
  • Animate orbs faster than a slow drift, and stop motion when people ask for reduced motion.
